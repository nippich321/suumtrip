# Suumtrip

Suumtrip is a mystery trip box for a two-day, one-night getaway. The customer selects a category (Sea, Old Town or Nature), a travel date and a mode of transport, pays with a Thai PromptPay QR code, and then opens the box to reveal the destination. The customer receives a complete itinerary for every part of the trip, together with a 2.5D map on which a 3D character walks or rides along the actual roads.

This project is an entry in the Software Development track, "Make Me Money", of All for One University.

## Project Structure

| File | Purpose |
|---|---|
| `index.html`, `css/style.css` | Single-page website; pages are switched with `#hash` routes |
| `js/app.js` | All screens: home, category selection, possible destinations, payment, box opening, trip, partner accommodation and corporate gifts |
| `js/itinerary.js` | Selects a place for each part of the day, and calculates times, sunrise and sunset, and each travel leg |
| `js/tripmap.js`, `js/traveler3d.js` | Tilted map (MapLibre) and low-poly character (three.js) |
| `js/promptpay.js` | Generates PromptPay QR codes according to the EMVCo standard |
| `js/config.js` | Prices, PromptPay ID, categories and modes of transport |
| `data/destinations.json` | Destination data generated by the scripts in `tools/` |
| `tools/fetch_pois.py` | Retrieves real restaurants, accommodation and attractions from OpenStreetMap (Overpass API) |
| `tools/build_data.py` | Assigns places to each part of the day and calculates real walking and driving routes with OSRM |
| `docs/checklist.csv` | List of all places, for the team to verify in Google Maps |
| `docs/TEAM_KIT.md` | Hotel call script, social media post, video script and answers for the judges (in Thai) |
| `AGENTS.md` | Roles and working rules for the AI agents on this project |

## Running Locally

```bash
python -m http.server 5173 --directory .
```

Then open http://localhost:5173.

## Updating the Data

```bash
python -I tools/fetch_pois.py
python -I tools/build_data.py
```

## Preparing Files for Upload

```bash
python -I tools/package.py
```

This creates a `dist/` folder that can be uploaded to Netlify, GitHub Pages or Cloudflare Pages. Pushing to `main` also deploys the site to GitHub Pages through `.github/workflows/pages.yml`.
